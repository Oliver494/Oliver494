## 🚀 Featured Project — Vareliox

**[Vareliox](https://github.com/Oliver494/Vareliox-AI)** is a local-first AI workspace and coding assistant for Windows and Linux.

It lets users work with **local or cloud AI models** while keeping control over their files, credentials and agent permissions.

### What Vareliox includes

- 🤖 Local AI with Ollama and LM Studio
- ☁️ Optional cloud AI providers
- 🗂️ A real project and file workspace
- 🧩 An AI coding agent with reviewable changes
- 🔐 File, terminal and permission controls
- 🐧 Windows and Linux support
- 🌍 Multi-language interface

> Vareliox is still evolving. I'm using it to learn, experiment and improve by working on a real software project.

[Explore Vareliox →](https://github.com/Oliver494/Vareliox-AI)
